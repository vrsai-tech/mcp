# Governance

`@vrsai/mcp` is an official SDK maintained by vrsai, not a community
foundation project.

- vrsai maintains this project and its official repository
  (`vrsai-tech/mcp`) and package (`@vrsai/mcp`).
- Maintainers have final responsibility for the public API, security
  posture, and releases.
- External contributions are welcome — see [CONTRIBUTING.md](./CONTRIBUTING.md).
- Acceptance of any contribution (issue, pull request, or proposal) is at
  maintainer discretion and is not guaranteed.
- Changes affecting payment/spend behavior, trust verification, or other
  security-sensitive or economic-effect code paths receive heightened review.
- Maintainership may expand over time as the project grows; changes to this
  document will reflect that when it happens.
