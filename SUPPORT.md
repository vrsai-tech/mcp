# Support

## Getting help

Use [GitHub Issues](https://github.com/vrsai-tech/mcp/issues) for:

- reproducible bugs;
- feature requests;
- documentation issues (unclear, missing, or incorrect docs).

When filing an issue, include:

- `@vrsai/mcp` version (`npm ls @vrsai/mcp` or your `package.json`);
- Node.js version (`node -v`);
- operating system;
- the MCP host/client you're using, if relevant;
- a minimal reproduction;
- expected vs. actual behavior;
- sanitized logs (see below).

## Security vulnerabilities

Do not report security vulnerabilities here. See [SECURITY.md](./SECURITY.md)
for private vulnerability reporting.

## Never paste sensitive data

Never paste any of the following into an issue, comment, or log excerpt:

- private keys or seed phrases;
- live wallet credentials;
- signed payment authorizations or payloads;
- secrets or API tokens;
- raw payment-journal file contents.

Redact these before sharing logs, or describe the shape of the data instead.

## No guaranteed SLA

This project does not currently offer a support SLA or a public support
email. Issues are triaged by maintainers as time allows.
